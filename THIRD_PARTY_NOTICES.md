# Créditos y materiales de terceros

Adaptación fan no oficial de The Binding of Isaac: Four Souls.
Las imágenes, nombres y textos de cartas incluidos proceden del catálogo del juego base
V2 en https://foursouls.com/ y pertenecen a sus respectivos titulares. Su inclusión no
otorga una licencia para redistribución comercial. Se conservan enlaces por carta en
`lib/cards.json`; no se atribuye su autoría al código de esta aplicación.

Las dependencias npm mantienen sus licencias respectivas. Tras `npm ci`, consulta
los archivos LICENSE y metadatos de cada paquete en `node_modules`. Las versiones
exactas quedan fijadas en `package-lock.json`.

Este ZIP entrega el código preparado para el usuario; no se añade una licencia global
que pretenda relicenciar las cartas, marcas o dependencias de terceros.

Referencias técnicas de la adaptación local:

- https://nodejs.org/download/release/v22.13.1/docs/api/sqlite.html
- https://vite.dev/guide/api-javascript
- https://developer.android.com/tools/aapt2
- https://developer.android.com/tools/apksigner
